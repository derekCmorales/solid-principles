# solid-principles

Skill de agente para **auditar, refactorizar, diseñar y explicar** SRP, OCP, LSP, ISP y DIP — y para **frenar el sobre-diseño**.

Ejemplos en TypeScript (NestJS, Fastify, Prisma, Next.js, React). El `SKILL.md` es el índice; cada principio vive en `references/`.

## Instalar en Cursor

```bash
git clone git@github.com:derekCmorales/solid-principles.git ~/.cursor/skills/solid-principles
```

O copia la carpeta a `~/.cursor/skills/solid-principles/`.

Paquete distribuible: `solid-principles.skill` (los `evals/` no van dentro del zip).

## Uso

Invócala al revisar diseño OO, clases grandes, acoplamiento, o al decidir si extraer una interface. El disparo está en el `description` del frontmatter de `SKILL.md`.
